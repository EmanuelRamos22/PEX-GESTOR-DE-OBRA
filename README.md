# Gestor de Obras V2

Projeto acadêmico / PEX desenvolvido em HTML, CSS e JavaScript puro.

## Como executar

1. Extraia a pasta.
2. Abra `index.html` no navegador.
3. O sistema já funciona sem servidor e salva tudo no LocalStorage.

## Módulos

- Dashboard
- Obras
- Clientes
- Orçamentos
- Estoque
- Movimentações de estoque
- Financeiro
- Relatórios
- Impressão de orçamento
- Dark mode
- Busca e filtros
- Responsividade

## Observação importante

Os dados ficam apenas no navegador/dispositivo atual. Limpar os dados do navegador pode apagar as informações.

A chave usada é:

`gestorObrasV2`

## Estrutura

- `index.html`
- `style.css`
- `script.js`
